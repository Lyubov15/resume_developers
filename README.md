# Савельева Любовь Андреевна — Fullstack-разработчик

Разрабатываю веб-приложения и цифровые сервисы на стыке frontend и backend: от проектирования интерфейса и клиентской логики до API, баз данных и интеграции внешних сервисов.

Мой основной фокус — **Fullstack-разработка, GeoTech и AI-интеграции**. В проектах работаю с React, Next.js, Angular, TypeScript, JavaScript, Node.js, Python, FastAPI и PostgreSQL. Умею разбираться в существующем коде, продумывать структуру приложения, реализовывать пользовательские сценарии и доводить функциональность до рабочего результата.

Использую AI-инструменты как помощника в разработке и рефакторинге, но самостоятельно проверяю решения, логику, качество кода и корректность интеграций.

## Избранные проекты

### Mini Shop — Telegram Mini App и каталог товаров

Прототип интернет-магазина с каталогом внутри Telegram и ботом для администрирования товаров.

- Разработала Telegram-бота на Aiogram для добавления товаров.
- Реализовала хранение данных в PostgreSQL и изображений в MinIO.
- Создала каталог на Next.js 15.
- Продумала stateless-архитектуру для запуска нескольких экземпляров приложения.
- Настроила Docker Compose и передачу изображений через Next.js API Routes.

**Стек:** Next.js 15, FastAPI, PostgreSQL, MinIO, Aiogram, Docker.

[Исходный код](https://github.com/Lyubov15/mini-shop)

### Shopping Malls — геоаналитическая платформа

Геоинформационная система для анализа торговой инфраструктуры и поиска перспективных территорий под размещение новых торговых центров. Проект включает интерактивную карту, пространственные расчёты и аналитическую панель; решение было внедрено в коммерческой компании.

- Интегрировала Leaflet и данные OpenStreetMap.
- Реализовала отображение торговых объектов, границ районов и пространственных барьеров.
- Разработала расчёт зон влияния и анализ территорий с недостаточной торговой инфраструктурой.
- Добавила фильтрацию по районам и размещение виртуальных торговых объектов.
- Реализовала аналитическую панель на основе модели Хаффа.

**Стек:** JavaScript, HTML5, CSS3, Leaflet, Turf.js, D3-Delaunay, Node.js, Express.

[Исходный код](https://github.com/Lyubov15/shopping_malls) · [Демо-версия](https://lyubov15.github.io/shopping_malls/Frontend/index.html)

### Messenger — веб-мессенджер с GREEN-API

Веб-приложение для отправки и получения сообщений WhatsApp через GREEN-API.

- Реализовала авторизацию через параметры экземпляра API.
- Добавила создание диалогов и отправку сообщений.
- Организовала получение входящих сообщений в реальном времени с помощью long polling.
- Реализовала оптимистичное обновление интерфейса и обработку сетевых ошибок.
- Адаптировала интерфейс для разных размеров экрана.

**Стек:** React 19, JavaScript, Vite, GREEN-API, CSS3.

[Исходный код](https://github.com/Lyubov15/messenger) · [Демо-версия](https://messenger-sigma-bay.vercel.app/)

### Booking App — сервис онлайн-бронирования

Веб-приложение для бронирования столика в ресторане с выбором даты, времени и количества гостей.

- Реализовала многоэтапную валидацию формы.
- Добавила проверку доступности времени бронирования.
- Разделила стили компонентов с помощью CSS Modules.
- Продумала обратную связь об ошибках и пользовательские сценарии.

**Стек:** Next.js 14, React 18, TypeScript, CSS Modules.

[Исходный код](https://github.com/Lyubov15/booking-app) · [Демо-версия](https://booking-app-28v5.vercel.app/)

### Dostaffkin — сервис оформления доставки

Сервис для расчёта стоимости, оформления и отслеживания доставки посылок.

- Реализовала расчёт стоимости с учётом маршрута, габаритов и скорости доставки.
- Интегрировала Яндекс.Карты и автодополнение адресов.
- Создала форму оформления заявки и отслеживание отправления по номеру.

**Стек:** Angular 21, TypeScript, RxJS, Яндекс.Карты API.
